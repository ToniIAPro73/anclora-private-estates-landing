## Vad det är

Anclora Private Estates Landing är den publika målsidan för leadinsamling för varumärket Private Estates. Den körs uteslutande i mörkt läge (inget temaval, ett medvetet beslut) med en växlare för 11 språk, vilket förstärker lyxvarumärkets visuella signatur.

## Kategori i ekosystemet

| Fält | Värde |
|---|---|
| Kategori | Ultra Premium (publik målsida) |
| Varumärkesaccent | `#D4AF37` |
| Typografi | Cardo + Inter + Fraunces |
| Kanoniskt repository | `anclora-private-estates-landing` |

## Huvudfunktioner

- Enbart mörkt läge med full Private Estates-identitet
- Växlare för 11 språk (inget temaval, med avsikt)
- Högvärdig leadinsamling

## Teknikstack

| Område | Teknik |
|---|---|

| Styling | Tailwind CSS |
| Testing | Vitest |

## Lokal start

```bash
npm install
npm run dev
```

## Språk som stöds

Produktionsprodukten stöder 11 språk: Español (standard), Català, Deutsch, English, Svenska, Français, Italiano, Dansk, Nederlands, Norsk, Português (`ULTRA_PREMIUM_LOCALES`, `src/lib/anclora-language-toggle.ts`). Denna dokumentation underhålls på alla 11 produktspråk.
