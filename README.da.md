## Hvad det er

Anclora Private Estates Landing er den offentlige landingside til leadindsamling for mærket Private Estates. Den kører udelukkende i mørkt tema (ingen temavælger, en bevidst beslutning) med en vælger til 11 sprog, hvilket forstærker luksusmærkets visuelle signatur.

## Kategori i økosystemet

| Felt | Værdi |
|---|---|
| Kategori | Ultra Premium (offentlig landingside) |
| Mærkeaccent | `#D4AF37` |
| Typografi | Cardo + Inter + Fraunces |
| Kanonisk repository | `anclora-private-estates-landing` |

## Nøglefunktioner

- Udelukkende mørk landingside med fuld Private Estates-identitet
- Vælger til 11 sprog (ingen temavælger, med vilje)
- Indsamling af værdifulde leads

## Understøttede sprog

Produktionsproduktet understøtter 11 sprog: Español (standard), Català, Deutsch, English, Svenska, Français, Italiano, Dansk, Nederlands, Norsk, Português (`ULTRA_PREMIUM_LOCALES`, `src/lib/anclora-language-toggle.ts`). Denne dokumentation vedligeholdes på alle 11 produktsprog.
