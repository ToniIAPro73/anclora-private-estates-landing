## Què és

Anclora Private Estates Landing és la landing pública de captació de la marca Private Estates. Funciona exclusivament en mode fosc (sense selector de tema, decisió deliberada) amb selector de 11 idiomes, reforçant la signatura visual de la marca de luxe.

## Categoria a l'ecosistema

| Camp | Valor |
|---|---|
| Categoria | Ultra Premium (landing pública) |
| Accent de marca | `#D4AF37` |
| Tipografia | Cardo + Inter + Fraunces |
| Repositori canònic | `anclora-private-estates-landing` |

## Funcionalitats principals

- Landing dark-only amb identitat completa de Private Estates
- Selector de 11 idiomes (sense selector de tema, per disseny)
- Captació de leads d'alt valor

## Stack tecnològic

| Àrea | Tecnologia |
|---|---|
| Frontend | React, TypeScript |
| Estils | Tailwind CSS |
| Testing | Vitest |

## Inici local

```bash
npm install
npm run dev
```

## Idiomes suportats

El producte en producció admet 11 idiomes: Español (predeterminat), Català, Deutsch, English, Svenska, Français, Italiano, Dansk, Nederlands, Norsk, Português (`ULTRA_PREMIUM_LOCALES`, `src/lib/anclora-language-toggle.ts`). Aquesta documentació es manté en els 11 idiomes del producte.
