## Cos'è

Anclora Private Estates Landing è la landing page pubblica di acquisizione del marchio Private Estates. Funziona esclusivamente in modalità scura (nessun selettore di tema, scelta deliberata) con un selettore di 11 lingue, rafforzando la firma visiva del marchio di lusso.

## Categoria nell'ecosistema

| Campo | Valore |
|---|---|
| Categoria | Ultra Premium (landing pubblica) |
| Accento del marchio | `#D4AF37` |
| Tipografia | Cardo + Inter + Fraunces |
| Repository canonico | `anclora-private-estates-landing` |

## Funzionalità principali

- Landing esclusivamente dark con identità completa Private Estates
- Selettore di 11 lingue (nessun selettore di tema, per design)
- Acquisizione di lead di alto valore

## Stack tecnologico

| Area | Tecnologia |
|---|---|
| Frontend | React, TypeScript |
| Stili | Tailwind CSS |
| Testing | Vitest |

## Avvio locale

```bash
npm install
npm run dev
```

## Lingue supportate

Il prodotto in produzione supporta 11 lingue: Español (predefinita), Català, Deutsch, English, Svenska, Français, Italiano, Dansk, Nederlands, Norsk, Português (`ULTRA_PREMIUM_LOCALES`, `src/lib/anclora-language-toggle.ts`). Questa documentazione è mantenuta in tutte le 11 lingue del prodotto.
