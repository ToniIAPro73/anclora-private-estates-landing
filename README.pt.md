## O que é

Anclora Private Estates Landing é a landing page pública de captação da marca Private Estates. Funciona exclusivamente em modo escuro (sem seletor de tema, decisão deliberada) com seletor de 11 idiomas, reforçando a assinatura visual da marca de luxo.

## Categoria no ecossistema

| Campo | Valor |
|---|---|
| Categoria | Ultra Premium (landing pública) |
| Destaque da marca | `#D4AF37` |
| Tipografia | Cardo + Inter + Fraunces |
| Repositório canónico | `anclora-private-estates-landing` |

## Funcionalidades principais

- Landing exclusivamente escura com identidade completa Private Estates
- Seletor de 11 idiomas (sem seletor de tema, por design)
- Captação de leads de alto valor

## Stack tecnológico

| Área | Tecnologia |
|---|---|
| Frontend | React, TypeScript |
| Estilos | Tailwind CSS |
| Testes | Vitest |

## Início local

```bash
npm install
npm run dev
```

## Idiomas suportados

O produto em produção suporta 11 idiomas: Español (padrão), Català, Deutsch, English, Svenska, Français, Italiano, Dansk, Nederlands, Norsk, Português (`ULTRA_PREMIUM_LOCALES`, `src/lib/anclora-language-toggle.ts`). Esta documentação é mantida nos 11 idiomas do produto.
