## Ce que c'est

Anclora Private Estates Landing est la page d'atterrissage publique de captation de la marque Private Estates. Elle fonctionne exclusivement en mode sombre (pas de sélecteur de thème, un choix délibéré) avec un sélecteur de 11 langues, renforçant la signature visuelle de la marque de luxe.

## Catégorie dans l'écosystème

| Champ | Valeur |
|---|---|
| Catégorie | Ultra Premium (page publique) |
| Accent de marque | `#D4AF37` |
| Typographie | Cardo + Inter + Fraunces |
| Dépôt canonique | `anclora-private-estates-landing` |

## Fonctionnalités principales

- Page en mode sombre exclusif avec identité complète Private Estates
- Sélecteur de 11 langues (pas de sélecteur de thème, par conception)
- Captation de leads à forte valeur

| Domaine | Technologie |

## Démarrage local

```bash
npm install
npm run dev
```

## Langues prises en charge

Le produit en production prend en charge 11 langues : Español (par défaut), Català, Deutsch, English, Svenska, Français, Italiano, Dansk, Nederlands, Norsk, Português (`ULTRA_PREMIUM_LOCALES`, `src/lib/anclora-language-toggle.ts`). Cette documentation est maintenue dans les 11 langues du produit.
