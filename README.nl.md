## Wat het is

Anclora Private Estates Landing is de publieke landingspagina voor leadgeneratie van het merk Private Estates. Werkt uitsluitend in donkere modus (geen themaschakelaar, een bewuste keuze) met een taalkeuzeschakelaar voor 11 talen, wat de visuele signatuur van het luxemerk versterkt.

## Categorie in het ecosysteem

| Veld | Waarde |
|---|---|
| Categorie | Ultra Premium (publieke landingspagina) |
| Merkaccent | `#D4AF37` |
| Typografie | Cardo + Inter + Fraunces |
| Canonieke repository | `anclora-private-estates-landing` |

## Belangrijkste functies

- Uitsluitend donkere landingspagina met volledige Private Estates-identiteit
- Taalkeuzeschakelaar voor 11 talen (geen themaschakelaar, met opzet)
- Genereren van hoogwaardige leads
